LES ÉTAPES

Un petit projet, un vrai workflow.

Tu vas pratiquer les principales étapes d'un déploiement d'application conteneurisée.

01

Construire

Créer une page HTML et la mettre en forme avec CSS.

02

Conteneuriser

Construire une image Docker basée sur Nginx pour servir le site.

03

Déployer

Créer un Deployment et un Service Kubernetes dans Minikube.

PowerShell

PS > docker build -t kube-start:v1 .

PS > minikube image load kube-start:v1

PS > kubectl apply -f k8s/

deployment.apps/kube-start created

service/kube-start created

OBJECTIF FINAL

Voir ton site depuis ton navigateur.

Une fois le Service créé, Minikube te donnera accès à ton application depuis ta machine.
